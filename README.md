# اختبار نظم المعلومات الجغرافية · لوحة المعلم

هذا الموقع فيه **لوحة المعلم**. تعرض نتائج اختبار نظم المعلومات الجغرافية للصف الثامن، مرتبة حسب الدرجة ثم الوقت. تقدر تفتحها من الآيفون أو من أي متصفح.

الطلاب يحلّون الاختبار من **برنامج الطالب (exe)** على لابتوبات المدرسة. وتلقى البرنامجين في صفحة **Releases** في هذا المستودع.

البرامج الثلاثة يتصلون بنفس المكان، وهو Google Apps Script:

```
برنامج الطالب (exe) ──► Apps Script + Google Sheet ◄── لوحة المعلم (هذا الموقع، أو برنامج المعلم exe)
```

## إعداد Apps Script (مرة وحدة)

1. افتح [sheets.new](https://sheets.new).
2. من القائمة اختر **Extensions ← Apps Script**.
3. الصق محتوى [`apps-script/Code.gs`](apps-script/Code.gs)، وغيّر `TEACHER_KEY` في أول سطر إلى كلمة سر من اختيارك.
4. اضغط **Deploy ← New deployment ← Web app**، واضبط الإعدادات كذا:
   - Execute as: **Me**
   - Who has access: **Anyone**
5. انسخ رابط **Web app URL**، وهو ينتهي بـ `/exec`.

## الاستخدام

- **برنامج الطالب:** أول مرة يطلب رابط Apps Script، ويحفظه في `script-url.txt` بجانبه. بعدها انسخ المجلد كامل لباقي اللابتوبات.
- **لوحة المعلم:** هذا الموقع أو برنامج المعلم. أول مرة تكتب الرابط وكلمة السر.
- **على الآيفون:** افتح الموقع من Safari، واضغط زر المشاركة ثم **إضافة إلى الشاشة الرئيسية**.

## ملاحظات

- الدرجة تنحسب من جديد في Apps Script، فما يقدر الطالب يغيّرها.
- إذا انقطع النت عند الطالب، تنحفظ النتيجة وتنرسل أول ما يرجع الاتصال.
- أي تعديل على `Code.gs` ما يشتغل إلا بعد ما تسوي **Deploy ← Manage deployments ← Edit ← New version**.
